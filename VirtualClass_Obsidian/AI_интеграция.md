# AI интеграция — Ollama

## Обзор

Модуль `AiModule` интегрирует **Ollama** — локальный ИИ-движок — для предоставления чат-ассистента и генератора заданий. Система автоматически обнаруживает доступные модели, сканирует файлы проекта для контекстной осведомлённости и поддерживает потоковый вывод ответов.

**Файлы**:
- `backend/src/ai/ai.module.ts`
- `backend/src/ai/ai.controller.ts`
- `backend/src/ai/ai.service.ts`

## Эндпоинты

### `POST /ai/chat`

Синхронный ИИ-чат. Возвращает полный ответ после завершения генерации.

**Тело**:
```json
{
  "messages": [
    { "role": "user", "content": "Объясни алгоритм сортировки" }
  ]
}
```

**Ответ**: полный сгенерированный текст.

---

### `POST /ai/chat/stream`

Потоковый ИИ-чат. Возвращает NDJSON stream — каждый chunk приходит в реальном времени.

**Тело**: аналогично `/ai/chat`

**Ответ**: поток JSON-объектов:
```
{"content": "Алгоритм "}
{"content": "сортировки "}
{"content": "пузырьком..."}
```

---

## Механизм работы

### 1. Разрешение модели

При каждом запросе `AiService`:

1. Запрашивает `GET {OLLAMA_BASE_URL}/api/tags` — список доступных моделей
2. Ищет предпочитаемую модель (по умолчанию `qwen3.5:cloud`, настраивается через `OLLAMA_MODEL`)
3. Если модель недоступна, перебирает fallback-модели по приоритету:
   - `qwen2.5:7b`
   - `llama3.1:8b`
   - `llama3.2:3b`
   - `gemma2:9b`
4. Если ни одна fallback-модель не найдена, берёт первую доступную
5. Результат кешируется на **10 минут**

### 2. Формирование контекста проекта

Система ИИ **контекстно-осведомлённая** — она сканирует файлы проекта и включает релевантные в системный промпт:

1. Определяет `PROJECT_ROOT` — корневая директория проекта
2. Сканирует все текстовые файлы (исключая `node_modules`, `.git`, `dist`, `build`, бинарные файлы)
3. Индексирует содержимое файлов (кеш на **5 минут**)
4. При получении запроса анализирует ключевые слова пользователя
5. Ранжирует файлы по релевантности (совпадение токенов в запросе)
6. Включает топ файлов в системный промпт (до **20 файлов**, до **8000 символов** каждый, максимум **160 КБ** общий контекст)

### 3. Эвристическая активация контекста

Контекст проекта активируется, когда запрос содержит:
- Ключевые слова на русском или английском, связанные с кодом: "код", "функция", "ошибка", "файл", "code", "function", "error", "file"
- Расширения файлов в запросе: `.ts`, `.tsx`, `.js`, `.py`, `.sql`, `.prisma`
- Путь к файлу, содержащий `/` или `.`

### 4. Отправка запроса в Ollama

```typescript
POST {OLLAMA_BASE_URL}/api/chat
{
  model: resolvedModel,
  messages: [
    { role: "system", content: systemPrompt },  // контекст проекта (если активирован)
    ...userMessages
  ],
  stream: true  // или false для синхронного режима
}
```

### 5. Парсинг потока

Ollama возвращает NDJSON-поток, каждый объект содержит:
```json
{ "message": { "role": "assistant", "content": "текст" }, "done": false }
```

Сервис извлекает `content` из каждого chunk и пересылает клиенту.

## Конфигурация

| Переменная | Описание | По умолчанию |
|-----------|----------|-------------|
| `OLLAMA_BASE_URL` | URL сервера Ollama | `http://localhost:11434` |
| `OLLAMA_MODEL` | Предпочитаемая модель | `qwen3.5:cloud` |

В Docker: `OLLAMA_BASE_URL=http://host.docker.internal:11434`

## Фронтенд-компоненты

### AIAssistant (`frontend/src/app/components/AIAssistant.tsx`)
- Чат-интерфейс для студентов
- Потоковый вывод ответов
- Использует `POST /ai/chat/stream`

### AIAssignmentGenerator (`frontend/src/app/components/AIAssignmentGenerator.tsx`)
- Генератор заданий для преподавателей
- На основе курса и темы генерирует задания

### UI компоненты
- `v0-ai-chat` — кастомный чат-компонент
- `claude-style-ai-input` — поле ввода в стиле Claude

## Поток данных

```
Пользователь (вводит запрос)
  │
  ▼
AIAssistant / AIAssignmentGenerator (фронтенд)
  │
  ▼ POST /ai/chat/stream
  │
AiController (бэкенд)
  │
  ▼
AiService
  ├── 1. Разрешить модель (Ollama /api/tags)
  ├── 2. Собрать контекст проекта (сканирование файлов)
  ├── 3. Сформировать system prompt
  └── 4. Отправить в Ollama /api/chat (stream=true)
        │
        ▼ NDJSON stream
        │
Ollama Engine (локально или удалённо)
        │
        ▼
AiService парсит stream → отправляет chunk'и клиенту
        │
        ▼
Фронтенд рендерит текст в реальном времени
```
