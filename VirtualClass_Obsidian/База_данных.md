# База данных — Prisma Schema

## Обзор

База данных: **PostgreSQL 15**, доступ через **Prisma ORM** с адаптером `@prisma/adapter-pg`.

**Файл схемы**: `backend/prisma/schema.prisma`
**Миграции**: 3 миграции в `backend/prisma/migrations/`

## Модели

### User (Пользователь)

Таблица всех пользователей системы (администраторы, преподаватели, студенты).

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `Int` | Автоинкрементный PRIMARY KEY |
| `email` | `String` | Уникальный email |
| `password` | `String` | Хеш пароля (bcrypt) |
| `name` | `String?` | Имя (опционально) |
| `firstName` | `String?` | Имя (детальное, добавлено в миграции 2) |
| `lastName` | `String?` | Фамилия (добавлено в миграции 2) |
| `group` | `String?` | Учебная группа (добавлено в миграции 2) |
| `specialtyCode` | `String?` | Код специальности (добавлено в миграции 2) |
| `role` | `String` | Роль: `"admin"` \| `"teacher"` \| `"student"`, по умолчанию `"student"` |
| `createdAt` | `DateTime` | Дата создания |

**Связи**:
- `taughtDisciplines` → `Discipline[]` (1:N, "TeacherDisciplines")
- `taughtClasses` → `Class[]` (1:N, "TeacherClasses")
- `enrollments` → `Enrollment[]` (1:N, "StudentEnrollments")
- `materials` → `Material[]` (1:N, "TeacherMaterials")

---

### Discipline (Дисциплина)

Учебная дисциплина, привязанная к преподавателю.

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `Int` | AUTO_INCREMENT PK |
| `name` | `String` | Название дисциплины |
| `credits` | `Int` | Количество кредитов (по умолчанию 5) |
| `teacherId` | `Int` | FK → User |
| `createdAt` | `DateTime` | Дата создания |

**Связи**:
- `teacher` → `User` (N:1, "TeacherDisciplines")
- `classes` → `Class[]` (1:N)

---

### Class (Класс/Курс)

Учебный класс, привязанный к преподавателю и (опционально) дисциплине.

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `Int` | AUTO_INCREMENT PK |
| `name` | `String` | Название класса |
| `description` | `String?` | Описание |
| `teacherId` | `Int` | FK → User |
| `disciplineId` | `Int?` | FK → Discipline (опционально) |
| `semester` | `String?` | Семестр |
| `createdAt` | `DateTime` | Дата создания |

**Связи**:
- `teacher` → `User` (N:1, "TeacherClasses")
- `discipline` → `Discipline?` (N:1)
- `enrollments` → `Enrollment[]` (1:N)

---

### Enrollment (Запись на курс)

Связующая таблица "многие-ко-многим" между студентами и классами.

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `Int` | AUTO_INCREMENT PK |
| `studentId` | `Int` | FK → User |
| `classId` | `Int` | FK → Class |
| `createdAt` | `DateTime` | Дата создания |

**Уникальный约束**: `@@unique([studentId, classId])` — студент не может быть дважды записан на один курс

**Связи**:
- `student` → `User` (N:1, "StudentEnrollments")
- `class` → `Class` (N:1)

---

### Material (Учебный материал)

Материал, загруженный преподавателем.

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `Int` | AUTO_INCREMENT PK |
| `title` | `String` | Название |
| `description` | `String?` | Описание |
| `type` | `String` | Тип: `"pdf"` \| `"video"` \| `"archive"` \| `"document"` \| `"spreadsheet"` \| `"url"` \| `"text"`, по умолчанию `"document"` |
| `courseName` | `String` | Название курса |
| `size` | `String?` | Размер файла |
| `url` | `String?` | URL файла или внешняя ссылка |
| `teacherId` | `Int` | FK → User |
| `isVerified` | `Boolean` | Верифицирован (по умолчанию `true`) |
| `createdAt` | `DateTime` | Дата создания |

**Связи**:
- `teacher` → `User` (N:1, "TeacherMaterials")

---
