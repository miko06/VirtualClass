# Бэкенд — NestJS API сервер

## Обзор

Бэкенд построен на **NestJS 11** с **TypeScript**, использует **Prisma ORM** для работы с **PostgreSQL 15**. Следует модульному монолитному паттерну — каждый домен представляет собой самостоятельный NestJS модуль.

**Точка входа**: `backend/src/main.ts` — запускает сервер на порту **3001**

## Конфигурация

### Переменные окружения (`backend/.env`)

| Переменная | Описание | Пример |
|-----------|----------|--------|
| `DATABASE_URL` | Строка подключения к PostgreSQL | `postgresql://vc:vc123@localhost:5432/vc` |
| `OLLAMA_BASE_URL` | URL сервера Ollama | `http://localhost:11434` |
| `OLLAMA_MODEL` | Предпочитаемая модель | `minimax-m2.5` |

### main.ts — конфигурация приложения

- **Порт**: 3001 (через `app.listen(3001)`)
- **CORS**: включён (`app.enableCors()`)
- **Статика**: `/uploads` обслуживается как статические файлы
- **Префикс**: нет глобального префикса (Nginx снимает `/api`)

## PrismaModule — глобальный доступ к БД

Модуль `PrismaModule` помечен декоратором `@Global()`, что делает `PrismaService` доступным во всех модулях без явного импорта.

```typescript
// prisma.service.ts
@Injectable()
export class PrismaService extends PrismaClient { ... }
```

Подключение к PostgreSQL через адаптер `@prisma/adapter-pg` (библиотека `pg`).

## Сервисы — бизнес-логика

### UsersService (`users/users.service.ts`)

| Метод | Описание |
|-------|----------|
| `findAll()` | Возвращает всех пользователей (без паролей) |
| `login(email, password)` | Поиск по email, сравнение bcrypt хеша, возврат данных пользователя или `UnauthorizedException` |
| `create(dto)` | Хеширование пароля (bcrypt, 10 раундов), создание пользователя с ролью "student" по умолчанию |

### ClassesService (`classes/classes.service.ts`)

| Метод | Описание |
|-------|----------|
| `findByTeacher(teacherId)` | Классы преподавателя с дисциплинами и записями студентов |
| `findByStudent(studentId)` | Классы, в которых записан студент (через Enrollment) |
| `create(dto)` | Создание класса, привязка к преподавателю и (опционально) дисциплине |
| `update(id, dto)` | Частичное обновление (название, описание, семестр) |
| `remove(id)` | Удаление записей (enrollments), затем удаление класса |

### MaterialsService (`materials/materials.service.ts`)

| Метод | Описание |
|-------|----------|
| `findAll()` | Все материалы с информацией о преподавателе, по убыванию даты |
| `findByTeacher(teacherId)` | Материалы конкретного преподавателя |
| `create(dto)` | Создание записи материала (`isVerified: true` по умолчанию) |
| `remove(id)` | Удаление записи из БД (файл остаётся на диске) |

Загрузка файлов: `FileInterceptor` с `Multer` (диск, лимит 500 МБ), файлы сохраняются в `/app/uploads/`.

### AdminService (`admin/admin.service.ts`)

| Метод | Описание |
|-------|----------|
| `getAllClasses()` | Классы с агрегированной статистикой по группам |
| `getGroups()` | Уникальные студенческие группы с количеством студентов |
| `getStudentsByGroup(group)` | Фильтрация студентов по группе |
| `enrollGroup(classId, group)` | Массовая запись всех студентов группы в класс (`skipDuplicates`) |
| `unenrollGroup(classId, group)` | Массовое удаление записей студентов группы из класса |
| `getTeachers()` | Список всех преподавателей |

## Валидация

Используется `class-validator` + `class-transformer` для DTO валидации. Пример — `CreateUserDto`:

```typescript
export class CreateUserDto {
  @IsEmail()
  email: string;

  @IsString()
  @MinLength(6)
  password: string;

  @IsOptional()
  @IsString()
  name?: string;

  @IsOptional()
  @IsEnum(['admin', 'teacher', 'student'])
  role?: string;
}
```

## Безопасность бэкенда

- **Хеширование**: bcrypt с 10 раундами соли
- **Нет guards/middleware**: эндпоинты открыты (без JWT/session)
- **CORS**: полностью открыт (`enableCors()` без ограничений)
- **Статика**: `/uploads` доступен без авторизации
