## n8n — AI Agent

Файл workflow: `n8n/virtualclass-ai-workflow.json`

### Структура workflow

1. **Webhook** — POST `/webhook/virtualclass-ai`, принимает `{ messages: [...] }`
2. **AI Agent** — обрабатывает запрос через LLM
3. **OpenAI Model** — GPT-4o-mini (настраивается)
4. **Respond to Webhook** — возвращает ответ

### Настройка

1. Откройте n8n UI: `http://localhost:5678`
2. Импортируйте workflow из файла
3. Настройте OpenAI credentials
4. Активируйте workflow

## Nginx — Обратный прокси

Файл: `nginx/nginx.conf`

### Маршрутизация

| Путь | Проксирование | Примечание |
|------|---------------|------------|
| `/api/users/login` | `backend:3001` | Rate-limited: 5 req/min/IP, burst 10 |
| `/api/` | `backend:3001` | Без ограничений |
| `/` | `frontend:4173` | SPA |

### Rate Limiting

```nginx
limit_req_zone $binary_remote_addr zone=login:10m rate=5r/m;
```

- Зона: `login`, 10 МБ памяти
- Лимит: 5 запросов в минуту на IP
- Burst: 10 запросов
- Применяется только к `/api/users/login`

## Бэкапы

Файл: `backup/scripts/backup.sh`

- Циклический запуск `pg_dump` с задержкой между итерациями
- Формат: `.dump` файлы в `backup/data/`
- Ретеншн: 7 дней (удаление старых бэкапов)
- Переменные: `PGHOST`, `PGUSER`, `PGDATABASE` (из Docker env)

## Безопасность

### Fail2ban

Файлы: `security/fail2ban/`

- **Jail**: `nginx-login` — фильтрует логи Nginx на 401/403 на `/users/login`
- **Действие**: бан IP на 2 часа
- **Критерий**: 3 неудачных попытки за 10 минут

### SSH

- Порт: 2222
- Аутентификация: **только по ключам** (пароли отключены)
- Ключи: `security/ssh/config/keys/`

### UFW Firewall

Файл: `security/firewall-setup.sh`

Открытые порты:
- `80/tcp` — HTTP (Nginx)
- `443/tcp` — HTTPS (Nginx)
- `2222/tcp` — SSH

Все остальные порты закрыты.

## CI/CD — Jenkins

Файл: `Jenkinsfile`

### Пайплайн (8 стадий)

| # | Стадия | Команда | Описание |
|---|--------|---------|----------|
| 1 | Checkout | `git checkout` | Получение кода |
| 2 | Frontend Install | `npm ci` (frontend) | Установка зависимостей фронтенда |
| 3 | Frontend Build | `npm run build` (frontend) | Сборка Vite |
| 4 | Backend Install | `npm ci` (backend) | Установка зависимостей бэкенда |
| 5 | Backend Lint | `npm run lint` (backend) | ESLint проверка |
| 6 | Backend Test | `npm run test` (backend) | Jest тесты |
| 7 | Docker Validate | `docker compose config` | Валидация docker-compose |
| 8 | Docker Build | `docker compose build` | Сборка образов |

### Доступ

- **URL**: `http://сервер:8081`
- **Docker socket**: проброшен внутрь контейнера Jenkins
- **Профиль**: `ci` (запускается отдельно от core сервисов)
