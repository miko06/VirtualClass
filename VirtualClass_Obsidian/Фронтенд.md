# Фронтенд — React + Vite SPA

## Обзор

Фронтенд построен на **React 18.3** с **Vite 6.3** как сборщик, **TypeScript**, **Tailwind CSS v4** и 53 кастомными shadcn/ui компонентами на базе **Radix UI**.

**Точка входа**: `frontend/src/main.tsx`

## Навигация

Проект **не использует** React Router или аналоги. Навигация реализована через состояние `activeTab` в `App.tsx`:

```tsx
// Упрощённая логика App.tsx
const [activeTab, setActiveTab] = useState('dashboard');

// Рендер в зависимости от роли
if (role === 'admin') return <AdminPanel />;
if (role === 'teacher') return <TeacherView activeTab={activeTab} />;
return <StudentView activeTab={activeTab} />;
```

Компонент `Dock` (macOS-стиль) управляет переключением вкладок.

## Управление состоянием

### ThemeContext
- Переключение светлой/тёмной темы
- Персистентность: `localStorage`
- Добавляет/удаляет класс `dark` на `<html>`

### AppDataContext
- Хранит содержимое курсов: лекции, практические работы, YouTube ссылки, задачи, СРО, чат, отправки
- Персистентность: `localStorage` (ключ `vc_app_data_v1`)
- Это **клиентское состояние** — содержимое курсов не хранится в БД

### MaterialsContext
- Синхронизируется с бэкенд API
- Автоматически загружает данные при монтировании
- Предоставляет CRUD операции над материалами

## API клиент (`api/client.ts`)

Кастомная обёртка над `fetch` с типизированными интерфейсами:

```typescript
// Пользователи
usersApi: { list, login, register, create }

// Классы
classesApi: { byTeacher, byStudent, create, update, remove }

// Материалы
materialsApi: { list, byTeacher, create, remove, uploadFile, fileUrl }

// Администрирование
adminApi: { getClasses, getGroups, getStudentsByGroup, getTeachers, enrollGroup, unenrollGroup }
```

Все запросы идут через Vite proxy в development (`/api`) или Nginx в production.

- **Framer Motion / Motion** (12.x) — переходы, анимации интерфейса
- **GSAP** (3.14) — сложные анимации
- **Spline** (4.1) — 3D сцены (`@splinetool/react-spline`)
- **Embla Carousel** (8.6) — карусели
- **Recharts** (2.15) — графики и диаграммы

## Конфигурация Vite

```typescript
// vite.config.ts (ключевые настройки)
export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: { '@': path.resolve(__dirname, './src') }
  },
  server: {
    proxy: {
      '/api': { target: 'http://localhost:3001', changeOrigin: true }
    }
  }
});
```

- Алиас `@` -> `./src`
- Proxy `/api` -> `localhost:3001` для development
